# randomInt
[[[desc randomInt
  間隔 [`start`, `end`) でランダムな整数値を返します。
]]]
[[[version randomInt
  
]]]

### Usage

```ts
import { randomInt } from 'parsnip-kit'

randomInt() // a random integer in [0, 10)
randomInt(0, 1024) // a random integer in [0, 1024)

```


### API

#### Arguments

[[[params randomInt
start:区間の左端
end:区間の右端
]]]

#### Returns

[[[returns randomInt

]]]
