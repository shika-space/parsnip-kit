# randomInt
[[[desc randomInt
  在区间 [`start`, `end`) 内返回一个随机整数值。
]]]
[[[version randomInt
  
]]]

### Usage

```ts
import { randomInt } from 'parsnip-kit'

randomInt() // a random integer in [0, 10)
randomInt(0, 1024) // a random integer in [0, 1024)

```


### API

#### Arguments

[[[params randomInt
start:区间左边界
end:区间右边界
]]]

#### Returns

[[[returns randomInt

]]]
